## 1. Project Overview & Classification

- **Project Name:** AI-Powered Content Course Knowledge and Script Generation
- **Core Mission:**
  1. Authenticate to a course website using the user's own authorized credentials/account.
  2. Discover courses, modules, and lessons.
  3. Collect normally accessible lesson text, transcripts, and captions.
  4. Analyze course materials using AI.
  5. Transform the ingested course material into a structured Content Knowledge Base.
  6. Retrieve relevant knowledge contextually.
  7. Generate high-quality content scripts via an AI provider abstraction.
- **Classification:** **Type A (Greenfield Software Project hosted in a Factory Repository)**

## 5. Security & Boundary Guardrails

1. **Credentials & Secrets:**
   - User course login credentials, session cookies, database connection strings, and Gemini API keys must never be hardcoded or committed to git.
   - All runtime configurations must use environment variables and `.env.local` / `.env` files, with `.gitignore` strictly blocking them.
2. **MCP Isolation:**
   - Subagents do not possess external MCP access. The Main Agent coordinates external gateways when authorized.
3. **Course Access & Legal/Ethical Compliance:**
   - Scraping/collection is limited to user's authorized access.
   - No external course sites were contacted or accessed during bootstrap.
